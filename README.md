# Lista de Tarefas em React

Aplicação de gerenciamento de tarefas desenvolvida com React.

O projeto permite adicionar, editar, visualizar e excluir tarefas utilizando Context API, React Router e localStorage.

---

## Funcionalidades

- Adicionar tarefas
- Editar tarefas
- Excluir tarefas
- Listar tarefas
- Persistência de dados com localStorage
- Navegação entre páginas com React Router
- Gerenciamento global de estado com Context API

---

## Tecnologias Utilizadas

- React
- Vite
- React Router DOM
- Context API
- JavaScript
- CSS
